# QA Test Plan

Owner role: QA Engineer

This document records durable QA planning standards and cross-slice test
strategy. Slice-specific BDD scenarios, test evidence, failures, and residual
risk belong in work-item dossiers.

## V3 QA Expectations

- Include BDD-style acceptance scenarios for user-visible or flow-visible
  behaviour.
- Include focused unit or contract tests for adapter boundaries.
- Record residual risk rather than treating green narrow tests as broad proof.
