## Documentation Standard

- Prefer factual, evidence-linked documents over prose dumps.
- Keep work-item artifacts in `/documents/work-items/{work_item_id}`.
- Promote only durable decisions, reusable guidance, and cross-slice knowledge
  into system-level documents.
