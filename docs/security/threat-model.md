# Threat Model

Owner role: Security Architect

This document records durable threat-model guidance for Agentic Mesh. Detailed
slice-specific threat analysis belongs in work-item dossiers.

## Current Trust Boundaries

- Human messaging connectors.
- Agent inbox broker and dead-letter storage.
- Safe-output tool surface.
- Source repositories and project repositories.
- Document-library adapter and OneDrive/SharePoint integration.
- Worker credentials and OAuth/API-key material.
