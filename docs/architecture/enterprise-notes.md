# Enterprise Architecture Notes

Owner role: Enterprise Architect

This document records enterprise-level constraints, capability impacts,
operating-model concerns, and governance guidance for Agentic Mesh.

## Current Enterprise Direction

- Agentic Mesh should support enterprise role networks beyond software
  delivery.
- Open-source core should remain useful; commercial features should improve
  enterprise adoption, governance, operations, and support.
- TOGAF is used as organising guidance, not as a rigid process dependency.
