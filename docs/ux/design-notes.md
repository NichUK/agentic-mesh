# UX Design Notes

Owner role: UX Designer

This document records durable UX direction for Agentic Mesh. Slice-specific
wireframes, flows, and interaction notes belong in work-item dossiers.

## Current UX Principles

- Humans should be able to interact with agents as specialist team members.
- Sponsor approvals and questions should be visible, direct, and easy to act
  on.
- Status surfaces should help users understand queue state, active work,
  blockers, evidence, and release status without reading raw JSON.
