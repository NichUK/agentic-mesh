# User Flows

Owner role: UX Designer

This document records durable user-flow guidance. Work-item-specific user flows
should link here only when they create reusable interaction patterns.

## Initial Flows

- Sponsor sends a direct message to a role agent and receives an in-role reply.
- Sponsor requests durable work; the responsible role proposes or creates a
  queue/work item with clear next action.
- Sponsor follows `/status` to a work-item detail page and then to artifact
  evidence.
