# Delivery Status

Owner role: Delivery Manager

This document records durable delivery-flow observations that outlive a single
work item. Current operational status remains in the runtime reporting plane;
slice-specific status and evidence belong in work-item dossiers.

## Status Themes

- Work should move through responsible roles via explicit handoff requirements.
- Blockers should identify the owner, required next action, and evidence needed
  to continue.
- Delivery notes should avoid making specialist product, architecture, QA, or
  release decisions for the accountable role.
