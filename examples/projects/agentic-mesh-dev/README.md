# Retired Agentic Mesh development example

This directory contains historical project material from the retired V3/V4
dogfood runtime. It is not an active deployment input and has no runnable
Compose profile.

V4 is dead. There is no migration, dual-run, or cutover path. The canonical V5
arms-length project declaration is under
`examples/projects/agentic-mesh-v5/`. Its deployment target is Linux Docker on
the LinuxCH host; project manifests and project-owned deployment artifacts are
the canonical inputs.

The remaining `project.yaml` is retained temporarily as classified historical
input while reusable content is assessed. Do not use it to start a runtime.
